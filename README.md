# JINGI — website

The public page of JINGI, served by GitHub Pages from `main`.

- `index.html` — the whole page, no build step.
- `img/` — screenshots from the game, the wordmark and the share card
  (`share.jpg`, 1200×630, what Facebook and Instagram show for the link).

The wordmark is an image on purpose: the title face (Sofachrome) is licensed
for static graphics, not for use as a web font. Body text is Kode Mono and
headings Unbounded, both under the Open Font License.

When the Steam page exists, replace the "Wishlist on Steam — soon" span in
the hero with a link to it.
